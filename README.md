### 🚀 Projeto em destaque

**Arenix Cloud** (cofundador e desenvolvedor): SaaS multi-tenant para gestão e locação de quadras de society.

- Motor de agendamentos com controle de concorrência de reservas
- Pagamentos com Mercado Pago e notificações em tempo real via Telegram
- Arquitetura em módulos independentes, orientada a eventos (TypeScript, Docker, Redis e filas)
- CI/CD no GitLab, observabilidade com Prometheus, Grafana e OpenTelemetry, e armazenamento com MinIO
